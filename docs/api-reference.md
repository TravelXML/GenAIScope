# API Reference

Complete reference for GenAIScope Python API.

## Inspector Class

Main entry point for all inspections.

```python
from genaiscope import Inspector

inspector = Inspector(**kwargs)
```

### Methods

#### `inspect_prompt(prompt: str, **kwargs) -> InspectionReport`

Analyze a prompt for quality and safety.

**Parameters:**
- `prompt` (str) - The prompt text to inspect

**Returns:**
- `InspectionReport` - Report containing evaluations and metrics

**Example:**
```python
report = inspector.inspect_prompt("What is the capital of France?")
print(report.summary())
print(f"Score: {report.evaluations[0].score}")
```

#### `inspect_rag(query: str, context: str, response: str, **kwargs) -> InspectionReport`

Analyze a RAG (Retrieval Augmented Generation) system.

**Parameters:**
- `query` (str) - The user query
- `context` (str) - The retrieved context
- `response` (str) - The generated response

**Returns:**
- `InspectionReport` - RAG analysis report

**Example:**
```python
report = inspector.inspect_rag(
    query="What is AI?",
    context="Artificial Intelligence is...",
    response="AI is Artificial Intelligence..."
)
```

#### `inspect_output(output: str, expected_format: Optional[str] = None, **kwargs) -> InspectionReport`

Validate and analyze model output.

**Parameters:**
- `output` (str) - The output text to inspect
- `expected_format` (str, optional) - Expected format (json, xml, csv)

**Returns:**
- `InspectionReport` - Output analysis report

**Example:**
```python
report = inspector.inspect_output('{"result": "success"}', expected_format="json")
```

## InspectionReport Class

Report generated by inspections.

```python
from genaiscope.core.models import InspectionReport
```

### Attributes

- `id` (str) - Unique report identifier
- `timestamp` (datetime) - When the report was created
- `title` (str) - Report title
- `description` (str) - Report description
- `input_text` (str, optional) - Input that was analyzed
- `output_text` (str, optional) - Output that was analyzed
- `evaluations` (List[EvaluationResult]) - List of evaluations
- `metrics` (Dict[str, float]) - Metric measurements
- `warnings` (List[str]) - Potential issues
- `errors` (List[str]) - Errors found
- `metadata` (Dict[str, Any]) - Additional data

### Methods

#### `summary() -> str`

Get a human-readable text summary.

```python
report = inspector.inspect_prompt("test")
print(report.summary())
```

## Analyzers Module

```python
from genaiscope.analyzers import (
    CostAnalyzer,
    PIIDetector,
    HallucinationDetector,
    SafetyAnalyzer,
    StructuredOutputValidator,
)
```

### CostAnalyzer

Estimate API costs.

```python
analyzer = CostAnalyzer()

# Estimate cost for a single call
costs = analyzer.estimate_cost("gpt-4", input_tokens=100, output_tokens=200)
# Returns: {"input_cost": 0.003, "output_cost": 0.012, "total_cost": 0.015}
```

**Methods:**
- `estimate_cost(model: str, input_tokens: int, output_tokens: int) -> Dict[str, float]`

**Supported Models:**
- gpt-4
- gpt-3.5-turbo
- claude-3-opus
- claude-3-sonnet
- gemini-pro

### PIIDetector

Detect and redact Personally Identifiable Information.

```python
detector = PIIDetector()

# Detect PII
detections = detector.detect("Email me at john@example.com")
# Returns: {"email": ["john@example.com"]}

# Redact PII
redacted = detector.redact("Email: john@example.com Phone: 555-1234")
# Returns: "Email: [EMAIL] Phone: [PHONE]"
```

**Methods:**
- `detect(text: str) -> Dict[str, List[str]]` - Find PII
- `redact(text: str) -> str` - Redact PII

**Detects:**
- email
- phone
- ssn
- credit_card
- ipv4

### HallucinationDetector

Detect potential hallucinations in generated text.

```python
detector = HallucinationDetector()

results = detector.detect(
    context="The sky is blue.",
    response="The sky is green and purple."
)
# Returns: {"hallucination_risk": 0.5, "contains_uncertainty": False, ...}
```

**Methods:**
- `detect(context: str, response: str) -> Dict[str, Any]`

**Returns:**
- `hallucination_risk` (float) - Risk score 0-1
- `contains_uncertainty` (bool) - Has uncertainty indicators
- `unsupported_statements` (int) - Statements not in context

### SafetyAnalyzer

Analyze text for safety issues, bias, and misinformation.

```python
analyzer = SafetyAnalyzer()

issues = analyzer.analyze("This is always bad and will never improve")
# Returns: {"bias": ["always", "never"], ...}
```

**Methods:**
- `analyze(text: str) -> Dict[str, List[str]]`

**Checks:**
- toxic - Harmful language
- bias - Absolute statements
- misinformation - Overconfident claims

### StructuredOutputValidator

Validate structured output formats.

```python
validator = StructuredOutputValidator()

# Validate JSON
result = validator.validate_json('{"name": "test"}')
# Returns: {"valid": True, "data": {...}}

# Validate XML
result = validator.validate_xml("<root></root>")
# Returns: {"valid": True}

# Validate CSV
result = validator.validate_csv("name,age\nJohn,30")
# Returns: {"valid": True}
```

**Methods:**
- `validate_json(text: str) -> Dict[str, Any]`
- `validate_xml(text: str) -> Dict[str, Any]`
- `validate_csv(text: str) -> Dict[str, Any]`

## ScoringEngine Class

```python
from genaiscope import ScoringEngine
```

Flexible framework for scoring and evaluation.

```python
engine = ScoringEngine()

# Score text
score = engine.score("Hello world", "length")

# Evaluate against threshold
result = engine.evaluate("Some text", "null_safety", threshold=0.5)

# Register custom scorer
def my_scorer(text: str) -> float:
    return 0.8 if len(text) > 10 else 0.2

engine.register("my_check", my_scorer)
```

### Methods

#### `score(text: str, scorer_name: str, **kwargs) -> float`

Score text using a registered scorer.

**Parameters:**
- `text` (str) - Text to score
- `scorer_name` (str) - Name of scorer to use
- `**kwargs` - Additional arguments for scorer

**Returns:**
- float - Score between 0.0 and 1.0

#### `evaluate(text: str, scorer_name: str, threshold: float = 0.5, **kwargs) -> EvaluationResult`

Evaluate text and return structured result.

**Parameters:**
- `text` (str) - Text to evaluate
- `scorer_name` (str) - Scorer name
- `threshold` (float) - Pass/fail threshold

**Returns:**
- `EvaluationResult` - Evaluation result with score and label

#### `register(name: str, scorer: Callable[[str], float])`

Register a custom scoring function.

**Parameters:**
- `name` (str) - Name for the scorer
- `scorer` (Callable) - Function that takes text and returns 0.0-1.0

### Built-in Scorers

- `length` - Score based on text length
- `null_safety` - Check if text is not empty

## Models Module

```python
from genaiscope.core.models import (
    EvaluationResult,
    InspectionReport,
    Provider,
    ScopeConfig,
)
```

### EvaluationResult

Individual evaluation result.

```python
result = EvaluationResult(
    score=0.85,
    label="pass",
    reasoning="Text is well-formed",
)
```

**Attributes:**
- `score` (float) - Score 0.0-1.0
- `label` (str) - Label like "pass", "fail", "warn"
- `reasoning` (str) - Explanation
- `metadata` (Dict) - Additional data

### ScopeConfig

Configuration object.

```python
config = ScopeConfig(
    provider="openai",
    model="gpt-4",
    temperature=0.7,
)
```

**Attributes:**
- `provider` (Provider) - Provider to use
- `api_key` (str, optional) - API key
- `model` (str) - Model name
- `max_tokens` (int) - Max tokens
- `temperature` (float) - Temperature
- `timeout` (int) - Timeout in seconds
- `retries` (int) - Number of retries

### Provider Enum

```python
from genaiscope.core.models import Provider

Provider.OPENAI
Provider.ANTHROPIC
Provider.GOOGLE
Provider.LOCAL
Provider.CUSTOM
```

## Configuration

```python
from genaiscope.core.config import get_config, set_config, Config
```

### set_config()

Set global configuration.

```python
config = Config(
    provider="openai",
    openai_api_key="sk-...",
    model="gpt-4",
)
set_config(config)
```

### get_config()

Get current configuration.

```python
config = get_config()
print(config.model)
```

## Errors Module

```python
from genaiscope.core.errors import (
    GenAIScopeError,
    ConfigurationError,
    ProviderError,
    ValidationError,
    EvaluationError,
)
```

Custom exceptions for error handling.

```python
try:
    report = inspector.inspect_prompt(prompt)
except ConfigurationError as e:
    print(f"Config error: {e}")
except EvaluationError as e:
    print(f"Evaluation error: {e}")
```

## Result Type

```python
from genaiscope.core.result import Result, ResultStatus
```

Generic result wrapper.

```python
result = Result(
    status=ResultStatus.SUCCESS,
    data={"key": "value"},
)

if result.is_success:
    print(result.data)
```

**Status Values:**
- `ResultStatus.SUCCESS` - Operation succeeded
- `ResultStatus.FAILURE` - Operation failed
- `ResultStatus.PARTIAL` - Partial success
- `ResultStatus.SKIPPED` - Operation skipped
