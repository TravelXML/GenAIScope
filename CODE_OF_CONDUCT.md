# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and inspiring community for all. We pledge to:

- **Be respectful** - Treat all members with respect and dignity
- **Be inclusive** - Welcome people of all backgrounds and experiences
- **Be collaborative** - Work together constructively
- **Be professional** - Keep interactions focused on the project

## Expected Behavior

- Use welcoming and inclusive language
- Be respectful of differing opinions and experiences
- Accept constructive criticism gracefully
- Focus on what is best for the community
- Show empathy towards other community members

## Unacceptable Behavior

- Harassment or discrimination of any kind
- Offensive comments related to gender, race, religion, etc.
- Personal attacks or ad hominem arguments
- Trolling, flaming, or intentionally disruptive behavior
- Any form of abuse

## Reporting Issues

If you experience or witness unacceptable behavior:

1. Report it to the project maintainers
2. Include details about the incident
3. Maintainers will investigate promptly
4. Actions will be taken as appropriate

## Scope

This Code of Conduct applies to all project spaces including:

- GitHub repositories
- Issue trackers
- Pull request discussions
- Chat channels
- Project events
