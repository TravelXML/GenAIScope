PROJECT OVERVIEW
════════════════════════════════════════════════════════════════════════════

GenAIScope is a complete production-quality Python library for inspecting,
testing, securing, optimizing, and operationalizing GenAI applications before
production deployment.

Tagline: "Inspect, test, secure, optimize, and operationalize GenAI
          applications before production."

COMPARISON WITH ALTERNATIVES
════════════════════════════════════════════════════════════════════════════

vs Langfuse:
  • GenAIScope: Pre-production toolkit
  • Langfuse: Production monitoring platform
  • Strategy: Use both (GenAIScope dev, Langfuse prod)

vs Ragas:
  • GenAIScope: Fast, lightweight, broad
  • Ragas: Advanced RAG-focused evaluation
  • Strategy: Quick checks with GenAIScope, detailed with Ragas

vs DeepEval:
  • GenAIScope: Simple one-liners
  • DeepEval: Comprehensive testing framework
  • Strategy: GenAIScope for basics, DeepEval for complex

vs Helicone:
  • GenAIScope: Local quality toolkit
  • Helicone: Production gateway service
  • Strategy: GenAIScope dev, Helicone prod monitoring
